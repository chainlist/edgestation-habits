# Habits

A habit tracker for [EdgeStation](https://github.com/chainlist/edgestation): one row per habit and
one square per day, ending today, like a contribution heatmap.

- **Tap a square** to check that day off, or to uncheck it. Days you forgot can be checked later.
- **+** adds a habit.
- **Tap a habit's name** to rename or delete it. Delete asks for a second tap, as it also removes
  the habit's history.

The number at the end of a row is the streak: the days in a row checked up to today. Until you
check today, it counts up to yesterday. A wider placement shows more days, and the list scrolls
when the habits do not fit. Each placement keeps its own habits.
